# UI Redesign

## Decisions

Decisions made by the human user in T3 thread 215d6e62-fefb-4bca-bd4b-45982430e536:

- All-In-One is rebuilt as one screen of the screen-by-screen redesign, after the render-states PNGs exist, using the shared design rather than a separate restyle. The target behavior follows CleanShot X: a mode pill with Area, Fullscreen, Window, Scrolling, Timer, OCR, and Recording; a width and height pill with an aspect-ratio dropdown; the remembered last selection; and a recording flyout offering Record Video, Record GIF, and Record in Studio Mode.
- All-In-One's default shortcut is Command-Shift-5, the same as CleanShot X, replacing the macOS Screenshot toolbar shortcut.
