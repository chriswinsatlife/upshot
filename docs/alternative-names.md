# Alternative Names

Upshot was forked from [fayazara/Screendrop](https://github.com/fayazara/Screendrop) at v0.38.0 and renamed. These names were considered alongside Upshot and remain available as alternatives.

- Eidolon: the Greek word for an image or likeness. The Mac App Store and Homebrew casks have no app with this name. The largest GitHub repository with the name is [artsy/eidolon](https://github.com/artsy/eidolon), a Swift project.
- Limner: a historical term for a painter who illuminated manuscripts. The Mac App Store has no app with this name. The largest GitHub repository with the name is [SignorMercurio/limner](https://github.com/SignorMercurio/limner), a Go project.
- Bigshot: the Mac App Store and Homebrew casks have no app with this name. [tapthaker/BigShot](https://github.com/tapthaker/BigShot) is an inactive iOS library for long screenshots.

Name availability was checked on 2026-11-12 against GitHub repository search, the Mac App Store, the iOS App Store, and Homebrew casks.
